정보세끼 업로더 · 시행일 2026년 9월 27일

1. 서비스 개요

정보세끼 업로더(이하 "앱")는 정보세끼 채널 운영자가 직접 제작한 쇼츠 영상을 운영자 본인의 YouTube 채널에 업로드하기 위한 개인용 프로그램입니다. 앱은 운영자 본인의 PC에서만 실행됩니다.

YouTube API 서비스 이용 안내

앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google의 정보 처리는 Google 개인정보처리방침을 따릅니다.

2. 이용하는 정보

  • Google 계정 권한: YouTube 동영상 업로드 권한(youtube.upload)과 YouTube 계정 관리 권한(youtube.force-ssl)을 요청합니다.
  • 업로드 권한은 운영자 채널에 영상을 올리는 데, 관리 권한은 운영자가 요청했을 때 이 앱이 올린 예약 영상을 삭제하는 데와, 제휴 상품이 소개된 운영자 본인 영상에 상품 링크와 광고 고지 문구가 담긴 댓글을 1개 다는 데에만 사용합니다.
  • 시청 기록, 구독 정보, 댓글, 연락처 등 다른 정보를 읽거나 바꾸지 않습니다.

3. 정보의 저장

로그인 후 발급되는 인증 토큰과, 업로드 후 받은 영상 ID(업로드한 영상 링크를 보여 주기 위한 것)는 운영자 PC 안의 파일에만 저장되며, 외부 서버로 전송되거나 제3자와 공유되지 않습니다.

4. 제3자 제공

앱은 어떠한 개인정보도 판매하거나 제3자에게 제공하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회

언제든지 Google 계정의 타사 앱 권한 페이지에서 앱의 접근 권한을 삭제할 수 있습니다. 삭제하면 앱은 더 이상 업로드할 수 없습니다.
